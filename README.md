# Series01 - RStudio

Data manipulation and exploratory analysis of student biometric data (IEAP 2025 cohort).

## Contents
- `Series01.qmd` — Quarto notebook with all the analysis (data import, visualization, statistical tests)
- `data/IEAP-2025.csv` — student dataset (name, weight, height, gender, etc.)

## Key analyses
- Descriptive statistics and visualizations (boxplot, histogram, density plot) of student weight
- Comparison of weight distribution between male and female students (Wilcoxon-Mann-Whitney test)
